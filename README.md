# Vietnam 2027

A small trip page for family and friends: countdown, route, places and day-by-day plan.

Single self-contained `index.html` (fonts and illustrations are inlined). Served with GitHub Pages from the `main` branch.

The pages (Home, Route, Places, one per stop, and Itinerary) are all sections of that one file. The part of the address after `#` picks the page, for example `#/places/hoian` or `#/days/2027-02-22`.

To check the "during the trip" view before departure, add `?at=` with a date and time, for example `?at=2027-02-22T03:00:00Z`.
